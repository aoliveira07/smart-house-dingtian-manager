# Smart House Dingtian Manager

Aplicativo 1.3.0 para organizar módulos Dingtian de 8, 16 e 32 saídas. Interface por Ingress e teste individual de relés antes de nomear ou habilitar uma saída. Instalação e atualização pela tela Aplicativos, sem HACS.

Requer Core 2026.9.2+, Supervisor e MQTT configurado. Usa a conexão MQTT do HA e preserva o inventário em `/data`. Acesso administrativo. Homologação física pendente.

Consulte a aba Documentação para instalar, migrar e usar.
